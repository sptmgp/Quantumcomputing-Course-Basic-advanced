Definición · Definition

¿Qué es el control óptimo cuántico?

What is quantum optimal control?

El control óptimo cuántico busca un campo de control dependiente del tiempo ε(t) (o amplitudes discretizadas u_k) que lleve a un sistema desde un estado o unitaria inicial hasta un objetivo con máxima fidelidad, sujeto a restricciones físicas de ancho de banda y amplitud.

Quantum optimal control seeks a time-dependent control field ε(t) (or discretized amplitudes u_k) that drives a system from an initial state or unitary to a target with maximum fidelity, subject to physical bandwidth and amplitude constraints.

GRAPE

GRAPE — Gradient Ascent Pulse Engineering

GRAPE — Gradient Ascent Pulse Engineering

Se discretiza el pulso en N intervalos de duración Δt, cada uno con amplitud de control constante u_k sobre el Hamiltoniano de control H_c.

The pulse is discretized into N intervals of duration Δt, each with a constant control amplitude u_k acting on the control Hamiltonian H_c.

U = Π_(k=N..1) exp[ −i(H_d + u_k·H_c)·Δt ]
F = |Tr(U_target† U)|² / d²
Propagador total y fidelidad.
Total propagator and fidelity.

GRAPE calcula analíticamente el gradiente exacto ∂F/∂u_k y realiza ascenso de gradiente — rápido y preciso con un simulador diferenciable.

GRAPE analytically computes the exact gradient ∂F/∂u_k and performs gradient ascent — fast and precise given a differentiable simulator.

Análisis · Analysis

El gradiente de GRAPE

The GRAPE gradient

Definiendo el estado propagado hacia adelante ρ_k = U_(1..k)ρ_0 U_(1..k)† y el objetivo propagado hacia atrás λ_k = U_(k+1..N)† U_target, el gradiente en el intervalo k es:

Defining the forward-propagated state ρ_k = U_(1..k)ρ_0 U_(1..k)† and the back-propagated target λ_k = U_(k+1..N)† U_target, the gradient at interval k is:

∂F/∂u_k  ∝  Im[ Tr(λ_k† · H_c · ρ_k) ]

→ El gradiente de cada intervalo se obtiene con un único barrido hacia adelante y uno hacia atrás, no con N² simulaciones separadas.

→ Each interval's gradient comes from a single forward sweep and a single backward sweep, not N² separate simulations.

The pulse height at time-slice k — the number GRAPE actually solves for.

The gate you wanted (X, Hadamard, CNOT...) — a fixed unitary matrix.

Analogía · Analogy

Ascenso vs. descenso — la misma montaña

Ascent vs. descent — the same mountain

▲ Gradient Ascent

Subir hacia la cima de la montaña — en la misma dirección del gradiente. Se usa para maximizar una cantidad, como la fidelidad F.

Climbing toward the mountain's peak — in the same direction as the gradient. Used to maximize a quantity, like fidelity F.

u_new = u_old + η·(∂F/∂u)

Ejemplo: GRAPE (fidelidad ↑)

Example: GRAPE (fidelity ↑)

▼ Gradient Descent

Bajar hacia el valle — en dirección opuesta al gradiente. Se usa para minimizar una cantidad, como una función de pérdida (loss).

Descending toward the valley — in the direction opposite the gradient. Used to minimize a quantity, like a loss function.

u_new = u_old − η·(∂L/∂u)

Ejemplo: redes neuronales (pérdida ↓)

Example: neural networks (loss ↓)

CRAB

CRAB — Chopped Random Basis

CRAB — Chopped Random Basis

CRAB parametriza el pulso con una base truncada de funciones (p. ej. senos/cosenos con frecuencias aleatorias) y optimiza solo esos pocos coeficientes con un algoritmo sin gradiente (p. ej. Nelder-Mead).

Útil cuando no se dispone de un simulador diferenciable o el gradiente exacto es difícil de calcular.

CRAB parametrizes the pulse with a truncated basis of functions (e.g. sines/cosines with randomized frequencies) and optimizes only those few coefficients with a gradient-free algorithm (e.g. Nelder-Mead).

Useful when no differentiable simulator is available, or the exact gradient is hard to compute.

GRAPE: gradiente exacto, N grande  ·  CRAB: sin gradiente, pocos parámetros
GRAPE: exact gradient, large N  ·  CRAB: gradient-free, few parameters
